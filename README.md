# UDP-Based-Digital-Circuits-in-Verilog
This repository implements a 4:1 Multiplexer, SR Latch, and D Latch using Verilog User-Defined Primitives (UDP), along with their testbenches for simulation and verification. Through this project, I learned to model both combinational and sequential logic using UDPs and gained a deeper understanding of Verilog primitive-based design.
